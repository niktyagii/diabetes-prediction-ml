# 🩺 Diabetes Prediction System (Machine Learning)

## 📌 Overview

This project is a Machine Learning-based system that predicts whether a person is likely to have diabetes based on medical input parameters. It uses a trained classification model along with preprocessing techniques to provide accurate and fast predictions.

---

## 🚀 Features

* Predicts diabetes risk using ML model
* Handles missing values using imputer
* Scales data using standard scaler
* Simple and interactive GUI (`gui.py`)
* Pre-trained model for instant predictions

---

## 🛠️ Technologies Used

* Python
* Scikit-learn
* Pandas
* NumPy
* Tkinter

## ⚙️ How to Run

1. Clone the repository:

```
git clone https://github.com/your-username/diabetes-prediction-ml.git
```

2. Navigate to the project folder:

```
cd diabetes-prediction-ml
```

3. Install dependencies:

```
pip install -r requirements.txt
```

4. Run the application:

```
python gui.py
```

---

## 🧠 How It Works

1. User enters medical data in the GUI
2. Data is preprocessed (missing values + scaling)
3. Model predicts diabetes outcome
4. Result is displayed instantly

---

## 🎯 Objective

The aim of this project is to demonstrate how Machine Learning can be used in healthcare for early detection of diabetes, helping in timely diagnosis and preventive care.
